# Moon Courier Crisis — frontend

React + TypeScript + Vite + TanStack Query. Карта реализована через SVG и HTML/CSS.

Полная инструкция запуска, правила, API, тесты и скриншоты находятся в [корневом README](../README.md).

Из корня проекта: `npm run dev`. Отдельно клиент: `npm --prefix client run dev`.

Backend должен быть запущен на `http://localhost:3000` либо по адресу из `client/.env` (`VITE_API_TARGET`).
